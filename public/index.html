⌨️ Guia Completo de Atalhos de Teclado

⏱️ Relógios & Cronômetro

  • Espaço : Iniciar / Pausar Cronômetro
  • R : Resetar Shot Clock para 24s
  • T ou Shift + R : Iniciar Shot Clock em 14s (uma vez)
  • P : Avançar Período / Quarto

🔴 Time 1 (Esquerda)

  • A : +1 Ponto
  • S : +2 Pontos
  • D : +3 Pontos
  • Z : -1 Ponto
  • F : +1 Falta
  • V : -1 Falta

🟡 Time 2 (Direita)

  • J : +1 Ponto
  • K : +2 Pontos
  • L : +3 Pontos
  • M : -1 Ponto
  • H : +1 Falta
  • N : -1 Falta

💾 Sistema & Visualização

  • Ctrl + : Aumentar Escala / Zoom
  • Ctrl - : Diminuir Escala / Zoom
  • Ctrl 0 : Restaurar Escala Padrão (100%)
  • F11 : Alternar Tela Cheia
  • F8 : Abrir Janela para Finalizar & Salvar
  • ? : Abrir esta janela de atalhos
📌 Nota: O jogo é salvo automaticamente a cada alteração. Ao recarregar a página (F5), o placar restaura exatamente de onde parou!
